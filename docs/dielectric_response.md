# Static and frequency-dependent dielectric response

[简体中文](dielectric_response.zh-CN.md)

ZStar contracts Born effective charge (BEC) tensors with Gamma-point phonon
eigenvectors to obtain mode effective charges, oscillator tensors, static
lattice response, and the complex frequency-dependent response. The reported
quantity follows the physical dimensionality of the system:

| `--dim` | Default response | Unit |
| ---: | --- | --- |
| 3 | relative dielectric tensor | dimensionless |
| 2 | sheet polarizability divided by vacuum permittivity | Angstrom |
| 1 | line polarizability divided by vacuum permittivity | Angstrom^2 |
| 0 | molecular Gaussian polarizability, alpha/(4 pi epsilon_0) | Angstrom^3 |

For `dim=1` and `dim=2`, ZStar does not present the vacuum-dependent
supercell dielectric tensor as an intrinsic material constant. An effective
3D normalization requires an explicit thickness or cross-sectional convention.
It still retains the source electric-field definition. A slab's perpendicular
intrinsic permittivity needs compatible screened macroscopic input and the
inverse-response conversion selected by `--slab-boundary macroscopic`.
See [field definitions and Raman units](response_conventions.md); this option
does not supply microscopic local-field screening missing from a PYATB input.

For isolated molecules, separate rigid translations and rotations before
interpreting a fixed-orientation vibrational response. A generic low-frequency
cutoff is not a substitute for that check. The [molecular Unified benchmarks](../examples/Shared_Response/README.md)
include an independent mass-weighted internal-subspace audit.

## Required files

- `qpoints.yaml`: Gamma-point frequencies, eigenvectors, masses, and cell.
- `Z-BORN-symm.out` or `BORN`: atomic BEC tensors in Phonopy atom order.
- `BORN`: optional electronic dielectric tensor followed by the BEC tensors.
- `phonopy.yaml`: optional companion structure file when `qpoints.yaml` does
  not contain the primitive cell metadata.

The static command evaluates the zero-frequency contraction:

```bash
zstar dielectric static --qpoints qpoints.yaml --born Z-BORN-symm.out \
  --dielectric BORN --dim 3
```

The frequency-domain command uses the same mode contraction and adds damped
Lorentz oscillators:

```bash
zstar dielectric freq --qpoints qpoints.yaml --born Z-BORN-symm.out \
  --dielectric BORN --dim 3 --broadening 8 \
  --max-frequency 800 --points 2501 --outdir dielectric_response
```

Plots are generated by default. Use `--no-plot` for data-only processing.
Modes below 5 cm-1 are excluded by default; change this with
`--acoustic-cutoff` only after inspecting the Gamma-point eigensystem.

## Bulk example: tetragonal HfO2

The retained P42/nmc HfO2 example uses ABACUS 3.10 LTS, PBEsol, the ONCV
pseudopotentials and TZDP 9-au numerical orbitals from `TZDP_9au`, a 100 Ry
cutoff, a 10x10x7 electronic mesh, and a 1e-8 SCF threshold.
The `BORN` file contains

```text
epsilon_infinity = diag(5.161604, 5.161604, 4.780272)
```

Reproduce the total response with:

```bash
zstar dielectric freq \
  --qpoints docs/paper_figures/source_data/hfo2/qpoints.yaml \
  --born docs/paper_figures/source_data/hfo2/Z-BORN-symm.out \
  --dielectric docs/paper_figures/source_data/hfo2/BORN \
  --dim 3 --broadening 8 --max-frequency 760 --points 2501 \
  --outdir hfo2_dielectric_response
```

The resulting total static tensor is

```text
epsilon(0) = diag(75.761034, 75.761034, 18.045191).
```

Because the electronic tensor is present, both the static tensor and the
frequency-dependent curve are explicitly labeled as **total relative
dielectric response**.

## Two-dimensional example: monolayer MoS2

The retained 2H-MoS2 example uses ABACUS/PBE-D3(BJ), a 33x33x1 electronic
mesh, a 3x3x1 phonon supercell, and a 1e-8 SCF threshold. Run:

```bash
zstar dielectric freq \
  --qpoints docs/paper_figures/source_data/mos2/qpoints.yaml \
  --born docs/paper_figures/source_data/mos2/Z-BORN-symm.out \
  --dim 2 --broadening 8 --max-frequency 500 --points 2501 \
  --outdir mos2_dielectric_response
```

The archived BEC file does not contain an electronic dielectric tensor, so
the result is deliberately labeled as the **lattice sheet polarizability**:

```text
alpha_2D,ph(0) / epsilon_0
    = diag(0.710457, 0.710457, 0.000006) Angstrom.
```

This quantity is independent of the arbitrary vacuum height. Add an electronic
sheet response only when it has been calculated with the same structure,
functional, pseudopotentials, basis, and normalization. Use `--thickness`
only when a documented effective-thickness convention is required.

## Output contract

`zstar dielectric freq` writes:

| File | Contents |
| --- | --- |
| `static_response.json` | zero-frequency tensor, unit, dimensionality, and electronic-background status |
| `ir_modes.csv` | mode frequencies, effective charges, and oscillator strengths |
| `ir_response_real.dat` | real part of the diagonal response |
| `ir_response_imag.dat` | imaginary part of the diagonal response |
| `dielectric_response.png` | quick-look response plot |
| `dielectric_response.pdf` | publication-quality vector plot |
| `dielectric_response.svg` | editable vector plot |
| `ir_summary.json` | calculation settings, response kind, and output inventory |

The response files carry an explicit header. It distinguishes a total response
from a lattice-only response and prevents a missing electronic tensor from
being silently interpreted as a physical `epsilon_infinity = 1` result.
