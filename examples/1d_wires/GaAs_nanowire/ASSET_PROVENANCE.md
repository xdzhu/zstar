# Numerical asset provenance

- Pseudopotentials: SG15 ONCV PBE v1.0 UPF files for As, Ga, and H. The UPF
  headers identify the ONCVPSP generator, cite Hamann, Phys. Rev. B 88,
  085117 (2013), DOI `10.1103/PhysRevB.88.085117`, and state a Creative
  Commons Attribution-ShareAlike 4.0 license.
- Numerical atomic orbitals: ABACUS Standard Orbitals 2.0, using the archived
  100 Ry As, Ga, and H files named in `input/STRU`.
- Structure: hydrogen-passivated GaAs nanowire reconstructed from Materials
  Cloud record `2023.148`, DOI `10.24435/materialscloud:46-wj`.

The copied filenames and file bytes are retained unchanged. Users should cite
the upstream data and verify the asset terms required by their institution or
redistribution channel.
