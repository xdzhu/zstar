# Cubic BaTiO3：统一框架的 BEC 与 Gamma 点声子

本例采用同一个 Pm-3m 立方结构和 PBEsol 设置，实测 unified 框架与
“旧 Cartesian BEC + 独立声子”流程的结果及核时。所有结果已经计算完成。
这里的旧流程不是此前采用显式正负位移的联合响应对照，不能混用分母。

## 一键运行

从当前源码安装 ZStar，将 PYATB 安装在同一 Python 环境，并通过
`zstar config` 设置 ABACUS 路径与 MPI/OMP 配置，然后执行：

```bash
bash run.sh
```

- `run/`：干净的 INPUT、KPT、STRU，以及 `assets/` 内的赝势、轨道。
- `results/`：已完成的 unified、旧 BEC、独立声子计算与逐项计时记录。
- `work/`：运行脚本创建的新计算目录；重复运行支持续算，不覆盖归档。
- `ZSTAR_WORK`：指定其他工作目录；脚本附加参数传递给 `zstar bec run`。

准备命令为 `zstar bec pre --stru STRU -i INPUT --pp assets --orb assets`。
采用现有五原子立方晶胞，a = 3.981415 A，DOJO 赝势和对应的 10-au 轨道，
PBEsol、100 Ry、Gamma 中心 9 x 9 x 9 网格、`scf_thr=1e-7`。
能隙为 1.686 eV。两条 BEC 路线使用相同的 19 x 19 x 19 Berry 网格、
31 x 31 x 31 直接静态电子响应网格，以及完整精度极化输出。
位移模长为 0.02 bohr，导数分母采用写入 STRU 后的真实坐标差。

## 效率与精度

| 比较项 | 旧 BEC + 独立声子 | Unified |
| --- | ---: | ---: |
| BEC 位移 | 9 | 3 |
| 额外声子位移 | 3 | 0 |
| 总 SCF 数，含参考结构 | 13 | 4 |
| ABACUS 核时 | 3.419 | 1.339 |
| PYATB 核时，含能隙检查 | 2.660 | 1.221 |
| 求解器总核时 | **6.079** | **2.560** |

实测节省 **57.9%** 核时，约 **2.37 倍**提速。位移计算减少 75%，
计入参考结构后总 SCF 数减少 69.2%。这是单次同条件实测，不是多次统计平均，
也不是对所有材料的固定提速承诺。

此前 6.116/2.578 的总值还计入了输入生成；论文效率表统一只统计 ABACUS
和 PYATB 求解器，原始逐命令计时记录仍保留。

实际位移为 Ba(x)、Ti(x)、O(x+y)。O 的两个非零分量均约为
0.007483695886 A；经位点对称操作展开后，各位点的方向矩阵都满秩。
最大原始 BEC 差异为 3.76e-4 e，最大声子频率差异为 0.041 cm^-1；
原始力常数的相对差异为 0.0592%。独立 Phonopy 重建与 unified 原始
力常数的最大差异为 5.33e-15 eV/A^2。

电荷中性投影后的 unified 结果为 Ba = 2.73366 e、Ti = 7.43984 e、
O_parallel = -5.86103 e、O_perpendicular = -2.15623 e。
原始张量、声学和规则残差及投影幅度均保留，不隐藏数值误差。

**该固定立方结构有三重简并的光学软模。** Unified 为 217.807i cm^-1，
独立声子为 217.766i cm^-1，二者一致。因此本例用于验证 BEC、Gamma 点
力常数和效率，不将其作为稳定相静态声子介电常数的例子。`run.sh` 不自动
调用静态介电后处理，也不会删除虚频来绘制看似稳定的谱。两条路线的电子
介电常数均为 6.872583。

## 无需 DFT 的归档核验

```bash
python verify.py
```

该脚本校验文件哈希，在临时副本内重新收集响应、独立比较旧流程，并检查
重新生成的位移数量。需要源码、NumPy 和 Phonopy，不需要 ABACUS/PYATB
可执行程序。大体积 Hamiltonian 和电荷密度中间文件不随本例分发；原始绝对
路径仅用于溯源，重新计算应使用 `run/` 与 `run.sh`。

计时按各成功命令的单调时钟运行秒数乘 40/3600 得到预留核时。
ABACUS 为 1 MPI x 40 OMP，PYATB 为 40 MPI x 1 OMP；节点均为双路
Xeon Gold 6248、40 物理核。旧声子任务独立从原子电荷启动，关闭不必要
矩阵与电荷导出；两条 BEC 路线都采用参考电荷的普通文件副本。
结构优化、Raman、非 Gamma 声子和离线核验不计入此表。
`worker.json` 是启动时快照，最终完成状态以 `completed.json` 和成功命令
记录为准。详细环境、原始计时与输入校验见 `results/`。
