# Asset provenance

The `run/assets/` directory contains the SG15/ONCV pseudopotentials and
ABACUS numerical orbitals used by this PBE+D3(0) case: `In_ONCV_PBE_FR-1.0.upf`,
`Se_ONCV_PBE_FR-1.1.upf`, `In_gga_10au_100Ry_2s2p2d1f.orb`, and
`Se_gga_10au_100Ry_2s2p1d.orb`. The original pseudopotential notices and
requested citations are retained in the files.
