# Asset provenance

The `run/assets/` directory contains the exact ABACUS assets used by this
case: `Mo.upf`, `S.upf`, `Mo_gga_7au_100Ry_4s2p2d1f.orb`, and
`S_gga_6au_100Ry_2s2p1d.orb`. The pseudopotential headers retain the original
generator and citation information. Please preserve those notices when
reusing the files; the ABACUS executable and PYATB are external dependencies.
