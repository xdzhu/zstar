# Asset provenance

The `run/assets/` directory contains the exact ABACUS PBE baseline assets for
H2O: `H.upf`, `O.upf`, `H_gga_9au_100Ry_3s2p.orb`, and
`O_gga_9au_100Ry_2s2p1d.orb`. The compact HSE record in `results/` was produced
with the separately documented HSE calculation; hybrid-DFT scratch files are
not redistributed.
