# H2O: PBE APT evidence

This retained ABACUS + PYATB archive supplies the PBE molecular APT and GAPT
values in the manuscript. Atom order and the original coordinate frame are
preserved. Indexed tensors use displacement rows and dipole columns; the
manuscript prints their transposes under its response-first convention.
These older literature-comparison records are distinct from the relaxed
paired efficiency benchmarks under examples/Shared_Response.

中文：本目录保存论文 PBE 分子 APT/GAPT 所依据的 ABACUS+PYATB 记录，
保留原子顺序与坐标系。旧张量是位移行、偶极列；论文按响应优先约定转置
显示。不要把本目录与 Shared_Response 中重新优化的效率基准混为一套数据。
