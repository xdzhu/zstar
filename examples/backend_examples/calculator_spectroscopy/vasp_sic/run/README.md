# Local VASP input set

Place the converged PBE SiC `INCAR`, `POSCAR`, `KPOINTS`, a matching licensed
`POTCAR`, and the completed Gamma-phonon `vasprun.xml` here before running the
parent `run.sh`. Keep all files at the same structure and electronic settings.

This backend-adapter example requires locally supplied VASP inputs; it is not
one of the eight self-contained ABACUS efficiency benchmarks. The parent
README describes the preparation steps and the retained spectrum results.
No POTCAR is distributed by ZStar.
