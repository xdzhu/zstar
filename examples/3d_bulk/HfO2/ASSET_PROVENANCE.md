# Asset provenance

The `run/assets/` directory contains the exact PBEsol tetragonal HfO2 assets:
`Hf.upf`, `O.upf`, `Hf_gga_10au_100Ry_4s2p2d1f.orb`, and
`O_gga_10au_100Ry_2s2p1d.orb`. These are the ONCV/TZDP-style files used for
the retained high-k reference. The original file notices and requested
citations are kept intact.
